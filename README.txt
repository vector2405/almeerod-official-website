AL-MEEROD ACADEMY WEBSITE
=========================

This is a complete, ready-to-use website for Al-Meerod Academy.

HOW TO USE
----------
1. Unzip this folder.
2. Open the folder and double-click "index.html" to view the website on your computer.
3. To put it online:
   - Buy a domain (e.g. almeerodacademy.com or almeerodacademy.com.ng)
   - Get web hosting (e.g. from Namecheap, Hostinger, or any Nigerian host)
   - Upload all the files and folders (index.html, about.html, css folder, js folder, images folder) to the public_html or www folder of your hosting.

NOTES
-----
- The contact form is front-end only (shows an alert). When you host the site, connect it to a form service (Formspree, Netlify Forms, or your own email backend).
- You can replace or add more photos in the images folder later.
- The website is fully responsive (works on phones, tablets and computers).
